# Domain docs

Single context: one `GLOSSARY.md` and `docs/adr/` at the repo root.

- Read `GLOSSARY.md` before naming things; use its terms.
- Record decisions as ADRs in `docs/adr/NNNN-slug.md`. Take the next free
  number at merge time, so parallel branches don't collide.
- Create either file lazily, when the first term or decision lands.
